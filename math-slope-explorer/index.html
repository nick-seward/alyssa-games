📜 How slope works

slope = rise ÷ run = how much the line goes up for each 1 step across

🪜 It's a staircase

Between any two points on a line you can draw a staircase step: walk across (the run), then climb up (the rise). Every step on the same straight line has the same shape.

📖 Read left to right

Always read a line like a book: from left to right. The run goes right. If the line climbs, the rise is positive. If it drops, the rise is negative (you went down).

⛰️ Bigger number = steeper

A slope of 3 is steeper than a slope of 1, and a slope of ½ is gentle. For downhill lines, ignore the minus sign: −3 is steeper than −1.

🧭 The four kinds

Positive: uphill ↗. Negative: downhill ↘. Zero: flat ➡ (rise is 0). Undefined: straight up and down ⬆ (run is 0, and we can't divide by 0).

Example: from (1, 1) to (3, 5) the run is 3 − 1 = 2 and the rise is 5 − 1 = 4, so slope = 4/2 = 2. That means for every 1 step across, the line goes up 2.
